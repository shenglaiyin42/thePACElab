# PaceLab 新成员入组指南

## 欢迎加入 PaceLab

欢迎加入 PaceLab！很高兴你来到这里，和我们一起开始接下来的学习与研究。

刚加入一个新的团队，总会有一些需要慢慢熟悉的事情。这份指南整理了课题组的基本信息、日常工作方式，以及入组初期需要完成的事项。你不必一开始就记住所有内容；遇到不清楚的地方，随时提出来就好。

## 关于 PaceLab

PaceLab 的全称是 **Pathogen Dynamics, Animal Movement, Global Changes, and Ecology Lab**。我们关注病原体动态、动物移动、全球变化与生态过程之间的联系。

目前，课题组的工作主要以数据分析和模型建模为主。未来随着研究项目的发展，我们会开展一些野外工作。

## 实验室理念

知之为知之，不知为不知。

聪明人更要用老实的方法做事情。

PaceLab 是一个共同学习、工作并拓展研究领域边界的团队。与此同时，每位成员的身体和心理健康同样重要。如果在生活或工作中遇到困难，或者觉得自己需要帮助，请及时与课题组负责人沟通。课题组不一定能解决每一个问题，但至少可以提供一个交流的空间，并尽可能给予协助或建议。

## 沟通与会议

组内与工作有关的沟通全部使用电子邮箱，以便记录和保存。与组外人员沟通时，可以根据对方的情况适当调整沟通方式。遇到紧急情况，可以通过电话、短信或微信联系。

每位成员都应与老师定期进行个人例会，讨论工作计划、研究进展和具体的技术细节。

课题组每周举行组内例会，会议时长和具体内容会提前安排。每位成员都应积极、负责地参加，并认真参与讨论。

每位成员都应尽快熟悉并熟练使用日历系统，将组内会议、工作时间节点等安排加入日历，并同步到电脑和手机等移动设备。

如果需要在固定的组内例会或个人例会之外单独与老师安排会议，请通过邮件沟通，并给出期望的会议时间。

## 工作邮箱

每位成员都需要自行申请 Outlook 邮箱。邮箱名称统一采用以下格式：

```text
名.姓42@outlook.com
```

例如，李雷的邮箱为：

```text
lei.li42@outlook.com
```

## GitHub 与代码管理

为了方便投稿时公开代码、促进组内代码交流并提高透明度，每位成员都需要注册 GitHub，并尽快熟悉和正确使用其基础功能，主要包括 `pull`、`push`、`branch`、`merge` 和 `commit`。

GitHub 是课题组代码管理的中枢。组内工作中产生的代码都应通过 GitHub 同步保存，每次修改和最终版本都应在 GitHub 中有所记录，方便组内成员查看和交流。

在相关结果正式发表之前，所有 GitHub repository 都必须设为 private，组内工作代码不得公开或提供给第三方。工作完成并正式发表后，相关 repository 可以设为 public，第三方可以通过论文或 GitHub 自行获取公开的代码。

## 文献管理

为了方便组内合作文章中的文献引用、插入和管理，组内成员统一使用免费的文献管理软件 Zotero。请从 [Zotero 官方网站](https://www.zotero.org/download/)下载安装，并尽快熟练使用。

## AI 工具的使用

课题组不禁止使用 AI，但使用者需要负责任地使用。无论 AI 用于论文写作、代码编写还是其他工作，组内都会对相关内容进行谨慎的质量把控。

使用者需要在保证准确性、科学性和可重复性的前提下，充分理解 AI 生成的内容，并能够向组内其他成员解释清楚。使用者对最终产出的内容负全部责任；在自己尚未理解的情况下，不应直接采用 AI 生成的内容。

### 代码编写

原则上鼓励使用 vibe coding 的方式编写代码。代码应在整个过程中进行详细、明确且准确的标注和解释，并通过 GitHub 与组内成员分享。开发中的代码可以在组内分享，但未经许可不能与组外人员分享。

### 文字处理

使用者必须对 AI 生成或处理的文字进行检查，并对最终使用的文字负全部责任。

### 订阅费用

AI 工具的订阅费用现阶段由补助金覆盖，之后会根据具体情况进行调整。

## 数据与文件存储

组内数据、数据文档、文本及其他工作文件的存储和分享，目前禁止使用百度网盘。使用其他网盘前需要先与老师讨论，因为不同服务在质量、稳定性和加密程度方面可能存在差异。

在尚未找到安全、合适的替代方案前，统一使用移动硬盘存储。需要移动硬盘，或者电脑存储空间不够的同学，可以向老师申请。

与组外合作者沟通时，如果对方通过百度网盘或其他方式向我们传送信息，可以根据实际情况接收。

我们向组外发送或分享文件和数据时，应通过电子邮件进行，不使用 QQ、微信等即时通讯工具。如果文件体积过大，可以临时使用百度网盘，但需要尽快通过邮件告知对方并留下记录；确认对方已经下载后，应立即将文件从百度网盘中彻底删除。

## 个人资料与课题组网站

每位成员需要提交一张个人照片，以及一份关于个人研究兴趣和研究经历的简介，以便将信息同步到课题组网站。照片不要求使用标准证件照，工作照或生活照都可以，主要用于向 community 展示成员的个人风采。

相关内容和格式可以参考 [PaceLab 官方网站](https://thepacelab.org)。

## 办公室工作与环境

### 工作时间

原则上，在没有其他课业或出差安排的情况下，成员应在每周工作日（周一至周五）每天在办公室工作满 8 小时。

课题组不鼓励超时加班，也不鼓励周末来办公室加班。成员可以根据自己的项目进展情况，有选择地加班。

### 请假与寒暑假安排

除国家法定节假日和学校寒暑假外，在正常学习和工作时间内需要离校的成员，应提前通过邮件向老师请假，并说明请假日期和简单理由。

寒暑假期间，研究生默认放假回家；如需留校，应通过邮件说明留校日期。博士后在寒暑假期间除国家法定节假日外默认正常工作；如需在工作日出行或不参与工作，应提前通过邮件向课题组负责人说明情况。

### 办公空间

办公室内仅讨论与工作有关的事情和具体工作情况。课余生活内容请勿在办公室内展开。

### 饮食与清洁

请避免在办公室内食用有强烈气味的食物。可以喝水、喝茶和喝咖啡，但应尽量避免在办公室内吃早餐、午饭或加热食物。

每天工作结束后，请清理自己产生的垃圾，不要将垃圾留在办公室过夜。

公共区域的垃圾和卫生每周清理一次。课题组全体成员（包括老师）每周轮流值班，负责清理垃圾和公共区域卫生。

茶叶等食品需要密封保存，并放在指定地点，以免滋生昆虫、细菌和霉菌，或吸引老鼠等动物。

### 日常管理

随着实验室管理和工作的推进，每位成员可能会承担一部分实验室日常管理和维护工作。具体工作会根据实际情况安排轮值或由专人负责。

## 办公用品与电子配件

如果需要办公用品或电子配件，请通过邮件向老师申请购买，并说明需要什么、用途以及申请原因。
