# PaceLab 新成员指南（合作指导版）

## 欢迎加入 PaceLab

欢迎参与 PaceLab 的学习、研究和合作！

这份指南主要介绍参与 PaceLab 相关项目时的基本协作方式。具体的培养、管理和工作安排，将根据项目情况，由共同指导老师协商确定。

## 关于 PaceLab

PaceLab 的全称是 **Pathogen Dynamics, Animal Movement, Global Changes, and Ecology Lab**。我们关注病原体动态、动物移动、全球变化与生态过程之间的联系。

目前，团队的工作主要以数据分析和模型建模为主。未来随着研究项目的发展，我们也会开展一些野外工作。

## 我们重视的事情

> 知之为知之，不知为不知。
>
> 聪明人更要用老实的方法做事情。

PaceLab 是一个共同学习、工作并拓展研究领域边界的团队。与此同时，每位成员的身体和心理健康同样重要。如果在生活或工作中遇到困难，或者觉得自己需要帮助，可以及时与项目负责人沟通。负责人不一定能解决每一个问题，但可以提供交流的空间，并尽可能给予协助或建议。

## 沟通与会议

组内与工作有关的沟通统一使用电子邮件，以便记录和保存。与组外人员沟通时，可以根据对方的情况适当调整沟通方式。遇到紧急情况，可以通过电话、短信或微信联系。

每位成员都应积极、负责地参加组内例会，并认真参与讨论。具体的组会内容将根据每学期的实际情况安排。

每位成员都应尽快熟悉并熟练使用日历系统，将组内会议、工作时间节点等安排加入日历，并同步到电脑和手机等移动设备。

如果需要在既定的组内例会或个人例会之外单独与老师安排会议，请通过电子邮件申请，并给出期望的会议时间。

## 工作邮箱

组内工作原则上不使用 QQ 邮箱。已有自己的工作邮箱（如学校邮箱），或者已经拥有 Outlook 邮箱的成员，可以继续使用现有邮箱。

如果目前没有合适的工作邮箱，请自行申请 Outlook 邮箱。邮箱名称统一采用以下格式：

```text
名.姓42@outlook.com
```

例如，李雷的邮箱为：

```text
lei.li42@outlook.com
```

## 必装软件与服务

每位成员都应在自己的工作设备上安装或配置以下软件和服务：

- Microsoft 365（Office 365，包括 Word、Excel、PowerPoint 等 Office 组件，以及 Outlook 和 OneDrive）
- R
- RStudio
- GitHub（注册并配置个人账号）
- QGIS
- Zotero
- Zoom
- 腾讯会议

## 代码与版本管理

涉及 PaceLab 项目的成员应使用 GitHub 管理相关代码，并熟悉 `pull`、`push`、`branch`、`merge` 和 `commit` 等基础功能。

项目代码应通过指定的 GitHub 仓库同步保存，重要修改和最终版本都应留下记录，方便项目成员查看和协作。

在相关结果正式发表之前，GitHub 仓库应设为 `private`，项目代码不得公开或提供给未经许可的第三方。工作完成并正式发表后，是否公开代码由项目组共同决定。

## 文献管理

涉及 PaceLab 合作文章时，原则上统一使用 Zotero 管理和插入文献。Zotero 可以从 [官方网站](https://www.zotero.org/download/)免费下载。安装后，请同时安装或启用浏览器中的 Zotero Connector，以及 Microsoft Word 中的 Zotero 插件。

## AI 工具的使用

PaceLab 不禁止使用 AI，但使用者需要对 AI 生成或处理的内容负全部责任。

无论 AI 用于论文写作、代码编写还是其他工作，使用者都应检查内容的准确性、科学性和可重复性，充分理解相关内容，并能够向其他项目成员解释清楚。在自己尚未理解的情况下，不应直接采用 AI 生成的内容。

使用 AI 辅助编写的代码应有清楚、准确的标注和解释，并按照项目要求通过 GitHub 与项目成员共享。未经许可，开发中的代码不得与项目外人员分享。

## 数据与工作文件

项目开始时，参与成员和共同指导老师应确认数据、文档及其他工作文件的存储和共享方式。

未经许可，不得将未公开的数据、代码、文档或研究结果上传至公开平台，也不得提供给项目外人员。向外部发送或分享项目文件前，应先确认相关权限和传输方式。

## 个人资料与课题组网站

每位成员需要提交一张标准大头照，以及一份关于个人研究兴趣和研究经历的简介，以便将信息同步到课题组网站。

相关内容和格式可以参考 [PaceLab 官方网站](https://thepacelab.org)。

## 其他安排

成员的培养管理、考勤、请假、办公地点和日常工作安排，以所属单位的规定以及共同指导老师协商确定的要求为准。
