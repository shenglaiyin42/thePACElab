# PaceLab 新成员入组指南

## 欢迎加入 PaceLab

欢迎加入 PaceLab！很高兴你来到这里，和我们一起开始接下来的学习与研究。

刚加入一个新的团队，总会有一些需要慢慢熟悉的事情。这份指南整理了课题组的基本信息、日常工作方式，以及入组初期需要完成的事项。你不必一开始就记住所有内容；遇到不清楚的地方，随时提出来就好。

## 关于 PaceLab

PaceLab 的全称是 **Pathogen Dynamics, Animal Movement, Global Changes, and Ecology Lab**。我们关注病原体动态、动物移动、全球变化与生态过程之间的联系。

目前，课题组的工作主要以数据分析和模型建模为主。未来随着研究项目的发展，我们也可能开展一些野外工作。

## 沟通与会议

组内与工作有关的沟通全部使用电子邮箱，以便记录和保存。与组外人员沟通时，可以根据对方的情况适当调整沟通方式。遇到紧急情况，可以通过电话、短信或微信联系。

每位成员都应积极、负责地参加组内例会，并积极参与讨论。具体的组会内容会根据每学期的实际情况安排。

每位成员都应尽快熟悉并熟练使用日历系统，将组内会议、工作时间节点等安排加入日历，并同步到电脑和手机等移动设备。

如果需要在固定的组内例会、周例会或个人例会之外单独与老师安排会议，请通过邮件申请，并给出期望的会议时间。

## 工作邮箱

每位成员都需要自行申请 Outlook 邮箱。邮箱名称统一采用以下格式：

```text
名.姓42@outlook.com
```

例如，李雷的邮箱为：

```text
lei.li42@outlook.com
```

## GitHub 与代码管理

每位成员都需要注册 GitHub，并尽快熟悉和正确使用 GitHub。

GitHub 是课题组代码管理的中枢。组内工作中产生的代码都应通过 GitHub 同步保存，每次修改和最终版本都应在 GitHub 中有所记录，并与组内成员分享。

未经许可，与组内工作有关的代码不得分享给第三方。

## 文献管理

为了方便组内合作文章中的文献引用、插入和管理，组内成员统一使用 Zotero。请在自己的工作设备上安装 Zotero，并尽快熟练使用。

## AI 工具的使用

课题组不禁止使用 AI，但使用者需要负责任地使用。使用者对 AI 生成的内容负全部责任，并需要进行事实核查和准确性验证。

### 代码编写

原则上鼓励使用 vibe coding 的方式编写代码。代码应在整个过程中进行详细、明确且准确的标注和解释，并通过 GitHub 与组内成员分享。

### 文字处理

使用者必须对 AI 生成或处理的文字进行检查，并对最终使用的文字负全部责任。

### 订阅费用

AI 工具的订阅费用现阶段由补助金覆盖，之后会根据具体情况进行调整。

## 数据与文件存储

组内数据、数据文档、文本及其他工作文件的存储和分享，禁止使用百度网盘等云盘。

在尚未找到安全、合适的替代方案前，统一使用移动硬盘存储。需要移动硬盘，或者电脑存储空间不够的同学，可以向老师申请。

与组外合作者沟通时，如果对方使用百度网盘等云盘，可以根据实际情况灵活调整；但组内数据不得使用这些云盘存储或分享。

## 个人资料与课题组网站

每位成员需要提交一张标准大头照，以及一份关于个人研究兴趣和研究经历的简介，以便将信息同步到课题组网站。

相关内容和格式可以参考 [PaceLab 官方网站](https://thepacelab.org)。

## 办公室工作与环境

### 工作时间

原则上，在没有其他课业或出差安排的情况下，成员应在每周工作日（周一至周五）每天在办公室工作满 8 小时。

课题组不鼓励超时加班，也不鼓励周末来办公室加班。成员可以根据自己的项目进展情况，有选择地加班。

### 办公空间

办公室内仅讨论与工作有关的事情和具体工作情况。课余生活内容请勿在办公室内展开。

### 饮食与清洁

请避免在办公室内食用有强烈气味的食物。可以喝水、喝茶和喝咖啡，但应尽量避免在办公室内吃早餐、午饭或加热食物。

每天工作结束后，请清理自己产生的垃圾，不要将垃圾留在办公室过夜。

公共区域的垃圾和卫生每周清理一次。课题组全体成员（包括老师）每周轮流值班，负责清理垃圾和公共区域卫生。

茶叶等食品需要密封保存，并放在指定地点，以免滋生昆虫、细菌和霉菌，或吸引老鼠等动物。

## 办公用品与电子配件

如果需要办公用品或电子配件，请通过邮件向老师说明情况。
