# PaceLab 新成员入组指南

欢迎加入 PaceLab！

这份指南用于帮助新成员了解课题组的基本工作方式，并完成入组初期需要设置的事项。指南目前是一个简要版本，后续会根据团队的实际需要逐步补充和更新。

## 1. 我们的工作

PaceLab 的研究工作主要包括数据分析和模型建模，未来也可能开展强度适中的野外工作。

我们鼓励成员：

- 保持开放、尊重和友善的沟通；
- 对研究过程进行清晰记录；
- 遇到问题时及时提出；
- 在合作中明确任务、进度和责任。

## 2. 日常沟通

入组后，请确认以下信息：

- 主要指导人和日常联系人；
- 课题组常用的沟通平台；
- 组会和一对一交流的时间；
- 请假、出差或无法按期完成任务时的沟通方式。

重要的研究决定、任务安排和截止日期，建议通过可以长期保存的方式进行确认，不仅保留在即时聊天记录中。

## 3. 邮箱与个人信息

新成员需要准备一个可以长期、稳定使用的工作邮箱，用于科研交流、论文投稿、学术平台注册及课题组相关事务。

### 邮箱名称

邮箱名称应尽量简洁、正式，并与自己的中英文姓名或学术署名保持一致。推荐使用以下形式：

- `firstname.lastname`
- `firstname.initial.lastname`
- 姓名拼音的清晰组合

请尽量避免使用昵称、生日、学号或含义不清的字符。

在注册前，请确认：

- 中文正式姓名；
- 英文显示姓名；
- 论文和学术活动中计划使用的标准署名；
- 邮箱名称的拼写方式。

### 账号安全

- 使用独立且强度足够的密码；
- 如服务支持，请开启双因素认证；
- 设置可靠的账号恢复方式；
- 不要与他人共享密码或验证码；
- 不要使用临时邮箱注册重要科研服务。

具体的邮箱服务和配置方法，将根据课题组所在机构及当时可用的服务另行说明。

## 4. 数据、代码与文件

数据分析和模型建模工作应尽量做到过程清晰、结果可追溯。

基本要求包括：

- 保存原始数据，不直接覆盖；
- 记录数据处理、模型设置和主要修改；
- 重要文件不应只保存在个人电脑中；
- 按课题组约定的位置保存和备份数据、代码与文档；
- 不将敏感或未公开资料上传到未经允许的公共平台。

具体的文件命名、目录结构、备份方式和代码管理规则将在后续版本中补充。

## 5. 野外工作

如参与野外工作，成员需要在出发前了解任务内容、时间安排、所需装备和安全要求。

未经必要说明或培训，不应独立开展存在安全风险的工作。具体要求将根据项目地点和任务类型另行提供。

## 6. 入组首周清单

- [ ] 确认主要指导人和日常联系人
- [ ] 加入课题组的沟通与协作平台
- [ ] 确认中英文姓名及学术署名
- [ ] 注册并测试工作邮箱
- [ ] 完成邮箱安全设置
- [ ] 获取所需的数据、代码和共享文件访问权限
- [ ] 了解组会和日常沟通安排
- [ ] 与指导人确认第一阶段的学习或研究任务

## 7. 需要帮助时

新人不需要在入组时立即熟悉所有流程。遇到账号、数据、研究任务、野外安全或团队协作方面的问题，请及时联系指导人或指定联系人。

如果现有说明不够清楚，也欢迎提出建议，帮助我们共同完善这份指南。
